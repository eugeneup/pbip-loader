# PBIP Loader

Запускай `python -m pbip_loader.cli` или `pbip-loader-cli` после установки Python-пакета. Терминальный интерфейс и CLI используют общую папку хранения и сессию Azure CLI текущего пользователя.

## Команды

| Команда | Когда использовать |
| --- | --- |
| `config` / `config --root '<путь>'` | Посмотреть текущую папку или задать согласованный с пользователем путь. |
| `refresh` | Собрать или обновить справочник рабочих областей, моделей и отчётов. |
| `search '<имя>' [--local all\|yes\|no]` | Найти модели по имени модели или области в сохранённом справочнике. |
| `download '<key>'` | Скачать модель и связанные отчёты. `--overwrite` заменяет весь локальный комплект, включая локальные правки. |
| `publish '<key>'` | Посмотреть путь и список целей без записи в Power BI. |
| `publish '<key>' --yes` | Обновить определения перечисленных объектов в их исходных областях. |

Бери `key` из результата `search`. При нескольких подходящих результатах уточни рабочую область и модель. Перед публикацией покажи путь и список целей из плана, включая отчёты в других областях. Применяй план, когда пользователь уже разрешил обновить эти объекты. Для `--overwrite` отдельно установи, что пользователь согласен на замену локальной папки.

Читай итоговый JSON из stdout, ход операции из stderr. Для скачивания и публикации сообщай успех при коде выхода 0, `ok: true` и `status: "verified"`. У выполненной публикации также будет `applied: true`.

## Если операция остановилась

- **Нет Azure CLI или сессии.** Попроси пользователя установить Azure CLI или войти в браузере под нужной учётной записью. `--allow-login` у `refresh`, `download` и `publish --yes` позволяет открыть браузер при отсутствии сессии. Вход и MFA выполняет пользователь.
- **Справочника нет или связи изменились.** Выполни `refresh` и повтори поиск и сверку целей. Если у пользователя нет прав на объект, уточни аккаунт или попроси его получить нужный доступ. При неполном локальном комплекте выясни, есть ли правки, которые нужно сохранить перед повторным скачиванием.
- **Папка занята другой операцией.** Дождись её завершения.
- **Ошибка публикации.** Проверь состояние и путь к журналу из сообщения CLI. `preflight_failed` означает сбой до записи, `rolled_back` — успешное восстановление определений. При `indeterminate` или `rollback_failed` остановись, сохрани журнал и резервные определения и согласуй проверку объектов в сервисе. Повторять запись можно после выяснения состояния.
