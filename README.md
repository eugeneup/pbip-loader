# PBIP Loader

Терминальное приложение, которое скачивает определения моделей и отчётов Power BI в формате PBIP и публикует локальные изменения обратно в Power BI Service. Для входа используется Azure CLI с рабочей учётной записью Microsoft. Для работы приложения не нужны Fabric Git Integration, XMLA или собственное приложение Microsoft Entra. Доступность скачивания и публикации зависит от лицензии, прав пользователя и настроек организации.

## Установка и запуск

Нужны Python 3.12+ и Azure CLI. [Установить Azure CLI для Windows](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli-windows?view=azure-cli-latest&pivots=msi) · [Для macOS](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli-macos)

1. Откройте терминал в папке с исходниками и выполните команду установки.

   ```powershell
   python -m pip install .
   ```

   Можно указать путь к папке с исходниками явно. Подставьте свой путь.

   ```powershell
   python -m pip install 'C:\Users\путь до исходников\pbip-loader'
   ```

2. После установки запустите приложение.

   ```powershell
   python -m pbip_loader
   ```

Готовый пакет `.whl` можно скачать из раздела [Releases](https://github.com/eugeneup/pbip-loader/releases) и передать путь к нему вместо точки в команде установки. На macOS используйте `python3`, если команда `python` недоступна.

## Быстрый старт

1. **Настройки.** Откройте настройки кнопкой с шестерёнкой и выберите папку для справочника и локальных проектов.
2. **Обновить структуру.** Приложение соберёт справочник доступных рабочих областей, моделей и отчётов. Обновите его после изменений в Power BI Service. Если сессии Azure CLI нет, откроется браузер для входа.
3. **Найти модель.** Ищите по названию рабочей области/модели или выберите в фильтре, какие модели показать по наличию локальной копии.
4. **Скачать модель.** В проект войдут модель и все связанные с ней отчёты из справочника, в том числе из других доступных областей. Для каждого отчёта создаётся отдельный `.pbip` со ссылкой на локальную модель. При повторном скачивании приложение попросит подтвердить замену всей папки. Настройки из прежних `.pbip` сохраняются, если их ссылки на отчёты по-прежнему действительны.
5. **Опубликовать модель.** Для полного локального комплекта приложение покажет путь, имена и ID объектов. Power BI Service обновит определения существующих объектов в их исходных областях. Добавленные меры или страницы появятся, удалённые исчезнут. Чтобы добавить или удалить целую модель или отчёт, измените состав объектов в Power BI Service и обновите справочник. Кэш `.abf` и служебные файлы `.pbi` в публикацию не входят. Обновление данных после публикации не запускается.

## CLI для консоли и скриптов

Запускайте `python -m pbip_loader.cli`. После установки пакета также доступна команда `pbip-loader-cli`.

CLI и терминальный интерфейс используют одну папку хранения, справочник и сессию Azure CLI текущего пользователя. Если папка уже настроена и справочник собран, начните с `search`. Перезапустите терминальный интерфейс, чтобы он подхватил изменения из CLI.

```powershell
python -m pbip_loader.cli config
python -m pbip_loader.cli config --root 'D:\PowerBI'
python -m pbip_loader.cli refresh
python -m pbip_loader.cli search 'Sales'
python -m pbip_loader.cli download '<key из search>'
python -m pbip_loader.cli publish '<key из search>'
python -m pbip_loader.cli publish '<key из search>' --yes
```

- `search --local yes` показывает скачанные проекты, `--local no` — модели без локальной копии. В результате есть ключ модели, список компонентов и путь локальной копии, если она найдена.
- `download --overwrite` заменяет всю папку проекта, включая локальные правки. `publish` показывает план, `publish --yes` применяет его.
- `--allow-login` разрешает открыть браузер при отсутствии сессии для `refresh`, `download` и `publish --yes`.
- Итог операции возвращается в stdout как JSON с полем `ok`, ход операции — в stderr. Коды выхода: `0` — успех, `1` — ошибка операции, `2` — неверные аргументы, `130` — прерывание.

## Локальное хранение

```text
Выбранная папка/
  .pbip-loader/
    catalog.sqlite3
    operation.lock
    sessions/
  Область/
    Модель/
      Модель.SemanticModel/
      Отчёт A.Report/
      Отчёт A.pbip
      Отчёт B.Report/
      Отчёт B.pbip
```

В `catalog.sqlite3` полный справочник хранится в `inventory`, а зарегистрированные локальные проекты — в `projects`. При проблемах с публикацией CLI или приложение покажет путь к журналу в `.pbip-loader/sessions/`.

## Сборка из исходников

Чтобы собрать Python-пакет из исходников:

```powershell
python -m pip wheel --no-deps --wheel-dir dist .
```

Готовый пакет `.whl` появится в `dist/`.
